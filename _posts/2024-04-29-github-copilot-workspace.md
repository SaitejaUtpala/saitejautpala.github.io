In 2024 I was a **Research SDE at Microsoft Research** on the GitHub Copilot Workspace team.

GitHub Copilot Workspace is a Copilot-native developer environment: you start from a repository or an
issue, Copilot proposes a plan, you edit the plan and the code, and you run everything in one place.
The [technical preview](https://github.blog/news-insights/product-news/github-copilot-workspace/)
was released in April 2024.
